# Schengen Visas from Iraq — Data Explorer (2015–2025)

An interactive, static dashboard exploring European Commission short-stay Schengen visa statistics recorded at consular locations in Iraq.

## What is included

- 2015–2025 trends for applications, visas issued, cases not issued and MEVs
- Iraq vs worldwide recovery index (2019 = 100)
- Interactive Europe map by year and indicator
- Country explorer for Schengen states represented in the Iraq dataset
- Baghdad vs Erbil descriptive comparison
- Germany–Erbil 2024–2025 case study
- Downloadable CSV/JSON data
- Methodology and limitations

## Data source

European Commission, Directorate-General for Migration and Home Affairs (DG HOME), annual statistics on short-stay visas issued by Schengen countries.

Important: figures are classified by the country/consular location where an application was lodged. They do not necessarily represent applicant nationality.

## Preview locally

Unzip the package and open `index.html` in your browser. The dashboard bundles its chart library and data locally, so no local server is required.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `iraq-schengen-visa-dashboard`.
2. Upload **the contents of this folder** so `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will publish the site at a URL similar to `https://YOUR-USERNAME.github.io/iraq-schengen-visa-dashboard/`.
